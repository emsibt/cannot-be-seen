Protected windows — real capture exclusion

These are Chromium windows this app creates and owns, so Windows lets us exclude them from screen capture. They stay fully visible to you and are absent from Teams, Meet, or any other capture — including screenshots taken with Win+Shift+S.
Logins persist. The browser profile is kept between launches, so you sign in to a site once and stay signed in — tick the site's own "remember me" and it survives restarts.

Rules — re-applied automatically

Nothing in this section hides a window from a share. Windows does not allow one process to exclude another app's window from capture — the API returns ERROR_ACCESS_DENIED for any window you don't own — which is why this app creates its own windows. So rules for other apps can only dim a window (translucent and click-through, but still captured) or hide it (gone from the screen, so also gone from the share, but you can't read it either). For anything you need to read privately while sharing, use a protected window above.
